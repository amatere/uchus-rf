В папке две версии приложения:

────────────────────────────────────────────
 ВАРИАНТ 1 — если есть Node.js (рекомендуется)
────────────────────────────────────────────

1. Откройте папку: node_version
2. Запустите файл: start.bat (двойным кликом)
   ИЛИ в терминале: node server.js
3. Откройте браузер: http://localhost:3000

   Администратор: логин Admin26, пароль Demo20
   Пользователь: зарегистрируйтесь на сайте

────────────────────────────────────────────
 ВАРИАНТ 2 — если Node.js НЕТ (универсальный)
────────────────────────────────────────────

1. Откройте папку: static_version
2. Дважды кликните на файл: index.html
3. Сайт откроется в браузере

   Администратор: логин Admin26, пароль Demo20
   Пользователь: зарегистрируйтесь на сайте

   ВАЖНО: Данные хранятся в браузере (localStorage).
   Если очистите историю браузера — данные пропадут.

────────────────────────────────────────────
 Проверка наличия Node.js:
────────────────────────────────────────────

Откройте терминал (cmd) и напишите:
   node --version

Если показывает версию (например, v18.xx) — Node.js есть.
Если ошибка "не является командой" — Node.js нет.
